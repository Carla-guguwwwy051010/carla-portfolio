# Personal OS｜功能说明

## 文档说明

本说明按“当前已实现”与“未来规划”分层。未列入当前能力的功能，不应在作品集中描述为已经上线。

## 一、当前已实现能力

### 1. 单文件 Web App

- 产品以单文件网页应用形式运行。
- 适合快速打开、演示与迭代。
- 当前不依赖完整后端服务。

### 2. LocalStorage 本地存储

- 用户操作产生的数据保存在浏览器 LocalStorage。
- 页面刷新后可继续读取本地数据。
- 清理浏览器数据、更换浏览器或设备可能导致数据不可用。
- 当前不提供云端备份、账号同步或多人协作保证。

### 3. Dashboard

- 作为系统首页和模块入口。
- 用于帮助用户查看个人系统中的重点与整体结构。
- 当前展示内容与交互以实际页面为准。

### 4. 场景模块

当前项目包含：

- PM Workspace
- Learning
- Journal
- Tutoring
- Creation
- Experience
- Health

这些模块分别承载产品工作、学习、日常记录、家教、创作、经历与健康等场景。具体增删改查范围以当前实现为准。

### 5. 当前 AI 展示

- 当前 AI 相关内容仅用于模拟或探索产品方向。
- 未接入可对用户自然语言进行可靠理解的真实大模型。
- 不应将模拟响应描述为真实智能分类、自动记录或自动执行。

## 二、未来规划能力

### 1. 模块 DIY

- 启用或隐藏模块。
- 调整模块顺序。
- 组合 Dashboard 卡片。
- 保存个人布局。
- 必要时恢复默认结构。

### 2. 基于身份的系统定制

- 选择一个或多个身份。
- 根据身份推荐模块组合。
- 根据当前重点定制首页。
- 支持用户覆盖系统推荐，不用身份标签限制功能。

### 3. 真实 AI 助手

- 接收聊天式文本输入。
- 未来支持语音转文字输入。
- 识别用户意图、实体、时间与上下文。
- 推荐记录应进入的模块。
- 生成结构化草稿，而非直接静默写入。
- 对歧义内容主动询问或提供候选项。

### 4. AI 操作安全机制

| 要求 | 功能表现 |
|---|---|
| 可预览 | 写入前展示目标模块、字段和值 |
| 可确认 | 只有用户确认后才执行正式写入 |
| 可撤销 | 已执行操作可恢复到变更前状态 |
| 可追溯 | 保存原始输入、解析结果、变更内容与时间 |

对于删除、批量修改等高风险操作，应增加二次确认，且不能仅依赖 AI 自行判断。

## 三、暂不承诺的能力

在没有真实实现与验证前，以下内容不作为当前产品能力：

- 云端账号与跨设备同步。
- 多人实时协作。
- 真实大模型自动分类和自动写入。
- 语音识别准确率或 AI 识别准确率承诺。
- 基于真实用户数据训练的推荐系统。
- 已验证的留存、效率提升或商业化结果。
