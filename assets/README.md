# Assets 目录说明

> 此目录用于存放所有项目相关的图片、视频、PDF 等静态资源文件。

## 目录结构

```
assets/
├── home/                   # Home 页面相关素材
├── projects/               # 项目相关素材
│   ├── lovememo/          # LoveMemo 项目素材
│   ├── personal-os/       # Personal OS 项目素材
│   └── vybcall/           # Vybcall Video 项目素材
└── about/                 # About 页面相关素材
```

## 使用说明

### Home 页面素材 (assets/home/)
- Hero 区域的个人照片
- 装饰元素（如当前使用的 base64 图片可以提取到此）

### 项目素材 (assets/projects/)
每个项目子目录可以包含：
- 项目封面图（用于项目列表卡片）
- 项目详情页头图
- 用户流程图
- 信息架构图
- 原型设计截图
- 产品截图
- 数据可视化图表
- 其他项目相关图片

### About 页面素材 (assets/about/)
- 个人照片
- 装饰素材（猫咪、星星、花朵等元素）
- 其他关于页面的视觉素材

## 当前状态

目前网站使用的图片全部以 base64 编码嵌入在 `index.html` 中。

如果未来需要替换图片或添加新图片，建议：
1. 将图片文件放入对应的 assets 子目录
2. 更新 `index.html` 中的图片引用路径
3. 或保持 base64 方式（便于单文件分发）

## 推荐的图片格式

- **封面图 / 大图**: JPG (压缩后体积小)
- **图标 / 插画**: PNG (支持透明)
- **截图**: PNG (保真)
- **流程图 / 架构图**: SVG (矢量，可缩放) 或 PNG
